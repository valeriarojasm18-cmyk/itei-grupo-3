# Valeria Rojas — Portafolio y Sistema de diseño

Sitio web del portafolio de **Valeria Rojas**, diseñadora gráfica digital, acompañado de su sistema de diseño.

El proyecto está hecho con HTML y CSS, sin dependencias externas ni instalación. Incluye una página de portafolio de desplazamiento continuo (con inicio, sobre mí, proyectos, recorrido creativo y contacto) y una página aparte que documenta las decisiones visuales del sistema: colores, tipografía, layout, profundidad, formas orgánicas, componentes, buenas prácticas y comportamiento adaptativo. Ambas páginas comparten la misma identidad visual (rosa #E65286 y verde lima #D0E86E, tipografías Camiro, Bricolage Grotesque y Questrial, formas florales y animaciones suaves).
